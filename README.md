# Prototipo Fourmakers

Protótipo de interface com Vite, React, TypeScript e shadcn-ui.

## Como rodar

Requisitos: Node.js e npm (ou [nvm](https://github.com/nvm-sh/nvm#installing-and-updating)).

```sh
npm i
npm run dev
```

## Scripts

- `npm run dev` — servidor de desenvolvimento
- `npm run build` — build de produção
- `npm run preview` — preview do build
- `npm run lint` — ESLint
- `npm run test` — testes (Vitest)

## Stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
